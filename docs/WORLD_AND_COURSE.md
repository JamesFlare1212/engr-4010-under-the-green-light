# 世界与课程背景

## 课程框架

ENGR 4010 Professional Development: Leadership Competencies 通过 Lead RPG 练习沟通、情绪管理、文化能力、批判性思考、工程伦理与协作。Co-GM 两人合作，主要任务是引导公会完成当周经历，给不同成员参与的空间，并带领讨论和交接。

Syllabus 第2、4页：GM 最高40分，自评平均20分、同学评价平均20分。实际评价表关注创新、全员参与、指导清晰、放心表达和 Co-GM 合作。这些是主持表现的评价，不是游戏内的成功率。

第8周 LMS 说明开始聚焦工程伦理，指定阅读 NSPE Code of Ethics。本地 NSPE 原件为课程分发的版本；引用其公众安全、能力边界、真实通报、承认错误与可持续发展主题。所有新剧情均为改编草案。

## 既有世界

- 母星：Nemorath；新星球：Heliora Prime。
- Guardians 总部：The Shell，外形像龟壳，内部是高科技实验室，有地形、生命与气象分析设备。
- 地区：Luminis Sea，温暖潮湿的海洋、崖壁、丛林；风和水是能源，暴风雨会导致洪水。
- Guardians 使命：保护其他生命、互相忠诚、积极沟通、对其他公会开放并协调目标。
- 合作对象：Builders、Linkers、Radiants、Life Weavers 等；原件中公会名称偶有不同写法。当前剧本沿用第6周课件的 Life Weavers。
- 已有生物：恶海鸥，以及上半身为鱼、下半身为人的 Maid-Mer。前次游戏记录中玩家选择与其交好。
- 既有任务：基础设施、饮水、食物、安置与保护 Nemorath 来者，跨公会合作并避免内部冲突。
- 第6周课件提到仓促建设、资源不足和临时医疗设施。

## 这次原创事件

地点是 The Shell 附近的独立外围泵站；12名本地维修人员被困。它不改写教师已经决定的四艘 Nemorath 运输船结果，也不接管其他小组的剧情。

“安全绿灯”是17:10低负荷测试的旧回传；故事当前17:40，预计17:52暴潮抵达。状态回传线损坏，现场机械指示仍可读取。Mira 批准过临时旁路，但满负荷验证未完成。

故事新增的保障包括：可容纳4人约两小时的上层避难室、20分钟独立诊所备用电源、额定8人的工作艇（2船员+6撤离者，跑两趟）、外部手动闸门和两份应急物资。它们都是草案事实，不是课程给定的工程规范。

三个 NPC：Mira 负责工程与设备，Tavi 负责真实通报，Dr. Vale 负责医疗交接。没有一个 NPC 是必须击败的反派；拒绝不真实签字不会让其拒绝救人。

## 相关但不应混用的材料

`first-co-gm-prep.docx` 中“20–25分钟、2–4次掷骰”针对首次怪物遭遇；它不是本次课堂时长的通用规定。
