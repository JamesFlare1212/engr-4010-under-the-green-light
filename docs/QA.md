## 浏览器人工走查

使用 T3 协作浏览器的桌面 1280×800 和手机尺寸 390×844 / 320×700，GM 与玩家使用独立浏览器资料：

- 通过界面创建精简实体骰房间，选择一个 GM 席位；通过邀请地址自动填码加入。
- 中文 GM 与英文玩家同步推进到协商、路线、三次执行、交接、复盘。确认玩家没有 GM 私密提示。
- 主导申请后唯一掷骰；GM 录入 7，差额 −3 自动发起补救投票。玩家同意后结果由转机提升为部分成功，仅扣一份物资。
- 转移成功撤出 12 人，隔离低骰仍保留已撤离人数，物资投票选择保留。最终设施未验证，人员结果不被覆盖。
- 生成事实通报草稿、填写负责人和更新时间、保存交接，玩家用英文提交反思，双方可见。
- 模拟客户端断开，验证离线写操作被阻止；恢复后身份 ID、成员数量和复盘进度保持，重新进入实时同步。
- 手机导航、证据阅读、申请、投票、结果和复盘无页面水平溢出；桌面可查看流程分叉和决定记录。
- 修复了房间码正则在 Svelte 属性中的插值、中文字体缺失、代理来源校验和手机房间工具入口。

## 生产模式浏览器检查

使用 Bun 直接提供 dist 与同源 WebSocket（3000 端口），验证创建、刷新恢复及虚拟骰：两名申请者中选出唯一主导，服务端生成骰点，界面播放骰子动画并保持实时同步。核对中文字体成功加载、房间深层链接正常、无水平溢出。修复生产 CSP 对 Vite 内联小字体的限制，并增加静态资源、深层路由与私密源文件访问回归。

## 邀请链接复制回归

在真实浏览器的原生邀请弹窗中，先复现弹窗外备用 textarea 无法聚焦，导致空选区仍可能返回复制成功，以及全局提示被弹窗遮挡的问题。修复后备用控件放在当前弹窗内，验证焦点和完整选区，复制完成即移除并恢复焦点；原生 Clipboard API 拒绝时继续尝试备用复制。

浏览器分别验证无 Clipboard API、原生写入拒绝后的备用路径、原生成功路径、所有复制方式被拒绝四种情况。备用路径实际选中完整邀请链接；成功时按钮和弹窗内显示双语确认，失败时选中可见链接并提示手动复制，不显示成功。验证中文 / 英文及 390×844 下反馈可见且无水平溢出。权限拒绝通过浏览器中替换相关 API 注入，不声称已覆盖所有硬件或操作系统剪贴板实现。

## GM 手动结束投票回归

协商、路线、物资三类投票均验证：全员投完仍保持开放，允许覆盖原选票，结束前不公开票数或应用结果；仅 GM 手动结束后结算并拒绝改票。成员移出名单不自动关票，空投票由 GM 结束且不产生决定。HTTP 验证玩家关票被拒绝、双 GM 同时结束只有一次成功、物资只在关票时消费一次。

真实浏览器使用独立 GM / 玩家身份验证：全员投完显示等待 GM、玩家成功改选、GM 不填写可选说明即可结束、最终只统计修改后的选项并锁定按钮；390×844 的 GM 结束按钮可操作且无页面水平溢出。

## 验证边界

来源校验后续回归：先用真实 Vite 代理复现无 `Sec-Fetch-Site` 请求返回 403，再将 `/api` 字符串简写替换为 `changeOrigin: false` 的对象配置，并对 WebSocket 显式保留 Host / Origin。localhost、IPv4 / IPv6 局域网的创建、加入和实时认证通过；错误来源和无效 Origin 继续返回 403。服务端不再依赖 Fetch Metadata 放行，因此兼容局域网 HTTP 和不提供该头的浏览器。修改 Vite 配置后需重启开发服务；已有房间与数据库无需清理。

Docker CLI / Engine 在此环境不可用，未执行镜像构建或实际 Compose 启动。已核实官方 `oven/bun:1.4.2-alpine` 标签存在并支持 amd64 / arm64；镜像构建包含与本地相同的类型检查、测试和构建。部署后仍应按 `docs/DEPLOYMENT.md` 检查容器健康、卷持久化和代理的 WebSocket。

手机尺寸验证不等于真实 iOS / Android 硬件测试。没有验证物理摄像头扫码、移动设备后台长时间休眠、Safari / Firefox 全套交互或真实公网 TLS 代理。朗读使用浏览器 Speech Synthesis，语音可用性取决于设备。本版不提供完全离线首次加载和多实例广播。
