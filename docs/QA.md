## 邀请链接复制回归

在真实浏览器的原生邀请弹窗中，先复现弹窗外备用 textarea 无法聚焦，导致空选区仍可能返回复制成功，以及全局提示被弹窗遮挡的问题。修复后备用控件放在当前弹窗内，验证焦点和完整选区，复制完成即移除并恢复焦点；原生 Clipboard API 拒绝时继续尝试备用复制。

浏览器分别验证无 Clipboard API、原生写入拒绝后的备用路径、原生成功路径、所有复制方式被拒绝四种情况。备用路径实际选中完整邀请链接；成功时按钮和弹窗内显示双语确认，失败时选中可见链接并提示手动复制，不显示成功。验证中文 / 英文及 390×844 下反馈可见且无水平溢出。权限拒绝通过浏览器中替换相关 API 注入，不声称已覆盖所有硬件或操作系统剪贴板实现。

## GM 手动结束投票回归

协商、路线、物资三类投票均验证：全员投完仍保持开放，允许覆盖原选票，结束前不公开票数或应用结果；仅 GM 手动结束后结算并拒绝改票。成员移出名单不自动关票，空投票由 GM 结束且不产生决定。HTTP 验证玩家关票被拒绝、双 GM 同时结束只有一次成功、物资只在关票时消费一次。

真实浏览器使用独立 GM / 玩家身份验证：全员投完显示等待 GM、玩家成功改选、GM 不填写可选说明即可结束、最终只统计修改后的选项并锁定按钮；390×844 的 GM 结束按钮可操作且无页面水平溢出。
