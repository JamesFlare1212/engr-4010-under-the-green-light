## 已有世界

- 母星 Nemorath，新星球 Heliora Prime。
- Guardians 总部 The Shell 形似龟壳，内部有地形、生命和气象分析设施。
- Luminis Sea 是温暖潮湿的海洋、崖壁与丛林区域，使用风水能源，暴风雨会引发洪水。
- Guardians 保护其他生命、互相忠诚、积极沟通，并与 Builders、Linkers、Radiants、Life Weavers 等公会协调。
- 既有生物包括恶海鸥及上半身为鱼、下半身为人的 Maid-Mer；此前 Guardians 选择与 Maid-Mer 友好接触。
- 世界已有基础设施、饮水、食物、避难者安置和临时医疗资源紧张的背景。本次故事不改写其他小组或运输船的既定结果。

## 本事件的虚构事实

十二名维修人员被困在 The Shell 附近一座独立的外围潮汐泵站，其中两人需要协助移动。现在是 17:40，预计 17:52 暴潮抵达。绿灯来自 17:10 的低负荷测试；回传线损坏使屏幕显示旧值，本地机械指示仍可读取。Mira 批准了临时旁路，但未完成满负荷验证。

所有路线使用通路、转移、隔离三个目标，基础 DC 为 12 / 12 / 13：

| 路线 | 已公开的主要代价 |
| --- | --- |
| The High Line / 崖壁吊运 | 备用电机留在下层，之后检修或更换 |
| The Quiet Water / 海上转运 | 损耗移动电池，留下低层工具箱；诊所备用不被挪用 |
| The Borrowed Channel / 外部泄洪 | 扰动育幼浅滩一季，安排修复并清理电机 |
| 自创或混合 | GM 与玩家明确三个目标的安排、假设和接受的代价 |

各路线都要停用总部非关键实验室到次日。已有保障必须在选择前公开：

- 上层干燥避难室可容纳四人约两小时；外部救援班在暴潮减弱后到达。
- 诊所有二十分钟独立备用电源，需具名交接，停泵不等于立即中断医疗。
- 工作艇额定八人，包括两名船员，每趟可转移六人，共两趟。
- 安全绳、吊带、手摇绞盘及外部手动闸门属于基本设备，两份应急物资另算。

## NPC 与叙事约束

Mira 负责工程和设备，担心信誉受损；Tavi 负责保留原始记录并发出真实、可行动的通报；Dr. Vale 负责按需求照护和医疗供电交接。三人均可合作，拒绝不真实签字不会导致他们拒绝救人，诚实通报不需要说服骰。

低骰仍提供关键线索和备用通路。人员结果为十二人撤离（可能两人需观察），或八人撤离、四人在避难室待援。隔离失败追加封锁、检修和供电安排，不能撤销已撤离人数，也不自动取消避难室保障。

通报是否真实取决于实际说法，不能用骰点改写；路线已接受的代价保留到交接。课堂讨论时间与故事十二分钟分别处理。算式、资源和推进规则见 [开发交接](DEVELOPMENT_HANDOFF.md)。
